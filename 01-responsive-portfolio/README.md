# Practical 1: Responsive Personal Portfolio Page

## Aim
Design and develop a modern, mobile-responsive personal portfolio webpage using semantic HTML5 and CSS3 (Flexbox & CSS Grid).

## Key Features & Concepts
1. **Semantic HTML5 Tags**: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`.
2. **CSS Layouts**:
   - **Flexbox**: Navigation bar, stats row, tech badges, cards.
   - **CSS Grid**: Projects showcase, skills matrix, about grid, contact box.
3. **Responsive Design**:
   - Viewport meta tag configuration.
   - CSS Media Queries for tablet (`max-width: 992px`) and mobile (`max-width: 768px`).
4. **Modern UI Aesthetics**:
   - CSS custom properties (variables) for theme management.
   - Glassmorphism, subtle gradients, hover transitions, and glowing shadows.
5. **DOM Interaction**:
   - Mobile hamburger menu toggle.
   - Scroll-spy active link highlighting.
